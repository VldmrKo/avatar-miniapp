# Своп: 2 ГБ

На ВМ 1966 МБ памяти и своп не настроен. Пока там один бот, это терпимо.
С добавлением второго сервиса и ffmpeg это становится опасно: при нехватке
памяти ядро убивает не того, кто запросил, а самого крупного — то есть
может прилететь соседнему боту, который ни при чём.

Один раз, до установки:

    sudo fallocate -l 2G /swapfile
    sudo chmod 600 /swapfile
    sudo mkswap /swapfile
    sudo swapon /swapfile
    echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

Проверить:

    free -m        # строка Swap должна показать 2047

Своп — страховка, а не рабочая память: если сервис в него полезет, всё
станет медленным, но ничего не умрёт. Плюс `MemoryMax=700M` в юните
ограничивает нас сверху, чтобы мы физически не могли съесть машину.
